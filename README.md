# RAG-based-Pdf-knowledge-Extractor-AI-chatbot
 PDF AI Assistant is a Multi-PDF RAG chatbot that enables users to upload up to 5 PDF documents and interact with them through a ChatGPT-style interface. Built using Streamlit, FAISS, Sentence Transformers, and Groq LLMs, it provides semantic search, intelligent retrieval, and accurate AI-powered answers across multiple documents in real time.
